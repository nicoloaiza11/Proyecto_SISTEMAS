1. CÓMO FUNCIONA
----------------

Reparto de rampas:
  - Massalin ........... rampas 1 y 2
  - Alliance One ....... rampas 3, 4 y 5
  - Cooperativa ........ las 5 rampas (1 a 5)

Reglas:
  - Cada rampa recibe UN SOLO TURNO POR FRANJA (franjas de 2 horas,
    de 06:00 a 22:00).
  - Cada empresa tiene un horario preferente:
      * Massalin y Alliance One: mañana (06:00 a 14:00)
      * Cooperativa: tarde (14:00 a 22:00)
  - El sistema asigna la rampa automáticamente cuando se asigna o se
    confirma un turno, y busca primero en el horario preferente de la
    empresa.
  - Fuera de su horario, una empresa solo puede tomar una rampa libre EL
    MISMO DÍA de la entrega. Para días futuros, las rampas quedan
    guardadas para la empresa que tiene la prioridad.
      Ejemplo: la Cooperativa pide un turno para el jueves y la tarde del
      jueves está llena -> el sistema le da el viernes a la tarde, no el
      jueves a la mañana. Pero si el mismo jueves la rampa 1 de las 10:00
      sigue libre, la puede usar.
  - El primero que reserva se queda con la rampa.
  - Se sigue respetando la capacidad por franja y la capacidad diaria de
    cada empresa (eso no cambió).

3. QUÉ TIENEN QUE HACER
-----------------------

  1) Traer los cambios:
       git switch dev
       git pull

  2) Si usan la db.sqlite3 del repo: ya viene migrada, no hace falta nada.
     Si usan su propia base (o PostgreSQL):
       python manage.py migrate
     La migración crea las 5 rampas, les asigna las empresas y le pone
     rampa a los turnos que ya estaban agendados.

  3) Para nuevas tareas, crear una rama nueva desde dev
     (ej. git switch -c feature_algo) y hacer el PR hacia dev.
